Detailed Description

A container that stores a collection of polymorphic drawable objects.

This class inherits from PointerVector, storing std::shared_ptr to DrawableObject instances. It provides templated convenience methods to add concrete derived classes directly by value/reference, automatically wrapping them in a shared pointer to take ownership of a copy of the object.
