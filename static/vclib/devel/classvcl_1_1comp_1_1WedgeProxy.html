Detailed Description

template<typename FaceType>
class vcl::comp::WedgeProxy< FaceType >

The WedgeProxy class represents a proxy (view) of a single wedge (corner) of a Face element.

It provides object-oriented access to all attributes associated with this wedge/corner:

  • Topological vertex and vertex index
  • Color (if HasWedgeColors<FaceType>)
  • TexCoord (if HasWedgeTexCoords<FaceType>)
  • Normal (if HasWedgeNormals<FaceType>)

Dual Index Spaces: Local Corner Index vs. Global Vertex Index

  • Local Corner Index (uint): Returned by index(). This is the 0-based position mIndex of this wedge/corner within the parent face's local Wedges ContainerComponent (0 <= index() < parentFace().vertexCount()). It is always a uint (e.g. 0, 1, or 2 for a triangle corner).
  • Global Vertex Index (IndexType): Returned by vertexIndex(). This is the global index of the topological vertex in the mesh's VertexContainer (parentFace().vertexIndex(index())). It is typed as IndexType (32 or 64 bit).

It automatically propagates constness from the parent Face.
