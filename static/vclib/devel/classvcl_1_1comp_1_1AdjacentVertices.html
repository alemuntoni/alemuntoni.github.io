Detailed Description

template<int N = -1, std::unsigned_integral Index = uint, bool TTVC = false, bool OPT = false>
class vcl::comp::AdjacentVertices< N, Index, TTVC, OPT >

The AdjacentVertices class is a container of Vertex indices. It is typically used by Vertex elements to store the 1-ring neighborhood of adjacent vertices.

It is a random access container having static or dynamic size (typically dynamic, N = -1).

Dual Index Spaces: Global Vertex Indices vs. Local Adjacency Positions

It is essential to distinguish between the two indexing spaces in this component:

  1. Global Vertex Index (IndexType):
    • The global index or ID of a vertex inside the mesh's VertexContainer (m.vertex(vi)).
    • Typed as IndexType (32 or 64 bit).
    • Sentinel value: NULL_INDEX (vcl::NULL_INDEX<IndexType>). Indicates that there is no adjacent vertex at this slot.
    • Returned by adjVertexIndex(uint i) and adjVertexIndexMod(int i).
    • Passed to search functions like containsAdjVertex(IndexType vi) and indexOfAdjVertex(IndexType vi).
  2. Local Adjacency Position (uint):
    • The 0-based position or slot i within this element's 1-ring adjacency list (0 <= i < adjVertexCount()).
    • Always typed as uint (uint32_t).
    • Sentinel value: vcl::UINT_NULL (0xFFFFFFFF), indicating that the queried vertex was not found in this element's adjacency list.
    • Passed as the position uint i to adjVertex(uint i), adjVertexIndex(uint i), and setAdjVertex(uint i, IndexType vi).
    • Returned by indexOfAdjVertex(IndexType vi).
Template Parameters
NThe size of the container, representing the number of storable adjacent vertices. If negative (default), the container is dynamic.
IndexThe unsigned integral type used to store indices (default uint).
TTVCIf true, the container size will be tied to the vertex count of the element.
OPTIf true, the component is optional.
