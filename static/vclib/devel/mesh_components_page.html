Components

A Component is a C++ class that describes a piece of data of an Element or of a Mesh, and exposes a list of member functions that allow to manipulate it. Every Component is identified by an entry in the vcl::CompId enumeration, which can be used to query or access components generically (e.g. element.template component<vcl::CompId::POSITION>()).

In VCLib, Components are divided into two categories depending on whether they belong to an Element or to the Mesh itself:

  • Element Components (defined in the vcl::comp namespace and listed in the Components group): describe per-element attributes (e.g. vcl::comp::Position, vcl::comp::Normal, vcl::comp::Color, vcl::comp::VertexReferences). Their data is not stored inside the Element itself, but in contiguous Structure of Arrays (SoA) vectors managed by the Element's Container (see Containers). An Element Component is therefore the description of the data (its type, its vcl::CompId, and whether it is persistent or optional) and of the member functions that the Element proxy exposes to access that data in the Container (e.g. vcl::comp::Color::color()). Element Components can be optional: in that case, their data vector is allocated by the Container only when the component is enabled at runtime (see VCLib Meshes). The Element Components that can be used by a specific Element are also aliased in the namespace of that Element (vcl::vert, vcl::face, vcl::edge, e.g. vcl::vert::Position3d, vcl::face::OptionalColor, vcl::edge::Qualityf).
  • Mesh Components (defined in the vcl::mesh namespace and listed in the Mesh Components group): represent mesh-wide attributes such as vcl::mesh::BoundingBox, vcl::mesh::Color, vcl::mesh::CustomComponents, vcl::mesh::Materials, vcl::mesh::Name, and vcl::mesh::TransformMatrix. Unlike Element Components, Mesh Components are inherited directly by the vcl::Mesh class and store their data directly inside the Mesh instance. When an attribute exists for both Elements and Meshes (such as Color or CustomComponents), the corresponding vcl::comp and vcl::mesh classes share the same vcl::CompId and expose a uniform member function interface.
