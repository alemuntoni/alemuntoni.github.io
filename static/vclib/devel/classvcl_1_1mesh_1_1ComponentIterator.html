Detailed Description

template<CompId COMP_ID, typename ContainerType>
class vcl::mesh::ComponentIterator< COMP_ID, ContainerType >

Random-access iterator over a single component column in an ElementContainer.

It yields references to the component data. By default, it jumps elements that are marked as deleted (jumpDeleted = true).

Template Parameters
COMP_IDThe ID of the component to iterate over.
ContainerTypeThe type of the container (mutable or const).
