Detailed Description

template<typename DerivedRenderApp>
class vcl::ViewerDrawerOpenGL2< DerivedRenderApp >

The ViewerDrawerOpenGL2 class is a concrete viewer drawer implementation for the OpenGL2 backend.

It provides the core rendering functionalities for a viewer, using OpenGL2.
