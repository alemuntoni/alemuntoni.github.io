Detailed Description

The AbstractGizmo class provides the base interface for rendering visual overlays (gizmos) in the scene.

Gizmos are interactive or informative graphical elements (e.g., trackball rings, directional light vectors) that are drawn on top of or within the 3D scene, but do not represent physical geometry of the model. Consequently, they do not provide bounding boxes and are not usually part of the core object vectors.
