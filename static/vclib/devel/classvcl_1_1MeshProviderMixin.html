Detailed Description

template<typename Derived, typename MeshType = Derived>
class vcl::MeshProviderMixin< Derived, MeshType >

A Mixin class that automatically implements the AbstractMeshProvider interface for a Mesh.

This class uses the Curiously Recurring Template Pattern (CRTP). It must be inherited by a class that also inherits from a valid Mesh type.

The template parameter Derived must be the final class that derives from both this Mixin and the Mesh. The Mixin uses static_cast to cast itself to Derived and access the mesh elements, so if Derived is not the actual derived class or does not inherit from a Mesh, the cast or the compilation will fail.

Template Parameters
DerivedThe class inheriting from this Mixin.
MeshTypeThe type of the mesh that provides the components. Defaults to Derived.
