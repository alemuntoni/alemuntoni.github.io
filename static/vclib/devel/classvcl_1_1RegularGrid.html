Detailed Description

template<typename Scalar, int N>
class vcl::RegularGrid< Scalar, N >

An N-dimensional regular grid defined by an axis-aligned bounding box and a fixed number of uniformly-spaced cells along each dimension.

The grid subdivides its bounding box into a lattice of rectangular (in 2-D) or box-shaped (in 3-D and higher) cells, all of the same size. It provides utilities to:

  • map a point in space to the cell that contains it;
  • map a flat cell index to its N-D coordinates and vice-versa;
  • query the geometric extent of individual cells;
  • iterate over all cells or over a sub-range of cells.
Template Parameters
ScalarFloating-point type used for coordinates (e.g. float, double).
NNumber of spatial dimensions (must be > 0).

Constructs a grid from a bounding box, per-dimension cell lengths, and a flag controlling how the bounding box is adapted.

The bounding box is always adapted so that it covers exactly full cells in every dimension, guaranteeing that cellLengths() returns exactly cellLens after construction.

The flag extendBBox controls the rounding direction used to derive from the input bounding box:

  • true (default) — round up: the cell count is and the maximum corner is extended outward so that the grid covers at least the original bounding box.
  • false — round down: the cell count is and the maximum corner is pulled inward so that the grid fits strictly inside the original bounding box.

Each dimension is guaranteed to have at least 1 cell regardless of the rounding direction.

Parameters
[in]bboxAxis-aligned bounding box of the grid.
[in]cellLens:Sidelengths of a single cell (one per dimension).
[in]extendBBoxIf true (default), round the cell count up and extend the maximum corner outward. If false, round the cell count down and pull the maximum corner inward.

Point< uint, PointType::DIM > bestGridSize ( const PointType &  lengths,
uint  nElements 
)

Computes the optimal cell counts for a RegularGrid given the grid extents and the number of elements to be stored in it.

The heuristic targets one element per cell on average by distributing cells proportionally to the side lengths of the bounding box. Degenerate dimensions (length smaller than 1e-4 of the diagonal) are assigned a single cell, and the remaining cells are distributed among the non-degenerate dimensions.

Each dimension is guaranteed to have at least 1 cell. If nElements is 0 or any length is non-positive, all dimensions are set to 1 cell.

Template Parameters
PointTypeA type satisfying the PointConcept. The scalar type and dimensionality are deduced from it.
Parameters

[in]nElementsNumber of elements that will be inserted into the grid.
Returns
Point whose i-th component is the recommended cell count along dimension i.
