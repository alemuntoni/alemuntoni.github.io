Detailed Description

Contains the settings for the viewer, such as the active render mode, exposure, and background visualization options.

enum class vcl::ViewerSettings::ToneMapping
strong

The tone mapping operators available when rendering.

Enumerator
NONE 

No tone mapping is applied.

BASIC 

Basic (Reinhard) tone mapping.

ACES_HILL 

ACES Filmic Tone Mapping (Hill).

ACES_HILL_EXPOSURE_BOOST 

ACES Filmic Tone Mapping (Hill) with pre-exposure boost.

ACES_NARKOWICZ 

ACES Filmic Tone Mapping (Narkowicz).

KHRONOS_PBR_NEUTRAL 

Khronos PBR Neutral tone mapping.

COUNT 

Number of tone mapping operators.
