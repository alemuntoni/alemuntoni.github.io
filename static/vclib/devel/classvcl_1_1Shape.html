Detailed Description

Base class for rendering simple 3D shapes.

The Shape class manages the GPU buffers (via MeshRenderBuffers) for a given triangle mesh and provides convenient methods to draw it with a flat color or a picking ID.

It is designed to be lightweight and used inside other drawables or gizmos. Shapes are movable but not copyable to prevent accidental duplication of GPU resources.
