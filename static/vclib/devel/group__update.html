Detailed Description

List of Mesh Update algorithms.

They allow to update components and properties of a mesh.

You can access these algorithms by including #include <vclib/algorithms/mesh.h>

◆ applyTransformMatrix()

template<MeshConcept MeshType, typename ScalarM>
void vcl::applyTransformMatrix ( MeshType & mesh,
const Matrix44< ScalarM > & matrix,
bool updateNormals = true )

Applies a 4x4 transformation matrix to the mesh.

This function multiplies the vertex positions of the mesh by the given 4x4 transformation matrix.

If updateNormals is true, all directional and differential geometric attributes present and available in the mesh are also updated using the rotation part of the transformation matrix (with scaling removed to preserve unit lengths):

  • Vertex normals (vcl::HasVertexNormal)
  • Face normals (vcl::HasFaceNormal)
  • Edge normals (vcl::HasEdgeNormal)
  • Face wedge normals (vcl::HasFaceWedgeNormals)
  • Vertex tangents (vcl::HasVertexTangent), including handedness flip if the transformation has negative determinant
  • Vertex principal curvature directions (vcl::HasVertexPrincipalCurvature)
Template Parameters
MeshTypeThe type of the mesh, which must satisfy vcl::MeshConcept.
ScalarMThe scalar type of the transformation matrix.
Parameters
[in,out]meshThe mesh to be transformed.
[in]matrixThe 4x4 transformation matrix to apply.
[in]updateNormalsWhether to update normals, tangents, and principal curvature directions. Default is true.

◆ rotate() [1/2]

template<MeshConcept MeshType, typename Scalar>
void vcl::rotate ( MeshType & mesh,
const Matrix33< Scalar > & m,
bool updateNormals = true )

Rotates the mesh using a 3x3 rotation matrix.

This function rotates the vertex positions of the mesh by multiplying them with the given 3x3 rotation matrix. The matrix scalar type is automatically cast to the scalar type of the mesh, allowing e.g. rotating a single-precision mesh with a double-precision rotation matrix.

If updateNormals is true, all directional and differential geometric attributes present and available in the mesh are also rotated:

  • Vertex normals (vcl::HasVertexNormal)
  • Face normals (vcl::HasFaceNormal)
  • Edge normals (vcl::HasEdgeNormal)
  • Face wedge normals (vcl::HasFaceWedgeNormals)
  • Vertex tangents (vcl::HasVertexTangent), including handedness flip if the rotation matrix has negative determinant
  • Vertex principal curvature directions (vcl::HasVertexPrincipalCurvature)
Template Parameters
MeshTypeThe type of the mesh, which must satisfy vcl::MeshConcept.
ScalarThe scalar type of the rotation matrix.
Parameters
[in,out]meshThe mesh to be rotated.
[in]mThe 3x3 rotation matrix.
[in]updateNormalsWhether to update normals, tangents, and principal curvature directions. Default is true.

void vcl::setFaceColorFromMaterial ( MeshType & m)

Sets the per-face color of a mesh according to a material assigned to each face.

This function assigns a color to each face based on the material associated with it. The color is derived from the base color of the material.

Note
The base color of the material is applied only if the material index is valid (i.e., less than the number of materials in the mesh).

Parameters
[in]mThe mesh whose faces will have their colors set.
