Detailed Description

The SettingsDialogTab that lets the user browse and customize all the input bindings (shortcuts) exposed by the viewer and its active editors.

The available ActionMapGroups are obtained on demand from mProvider (e.g. a callback into the viewer), so the tab always reflects the editors that are currently pushed into the viewer.
