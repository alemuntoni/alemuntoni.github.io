Detailed Description

template<typename Scalar, uint N>
class vcl::OrthoBasis< Scalar, N >

An N-dimensional orthonormal basis.

An OrthoBasis is a set of N mutually orthonormal vectors that define a coordinate frame orientation in R^N (without any origin point). It provides linear conversions between local (frame-relative) and world (global) direction vectors.

Note
Both toWorld and toLocal are pure linear transforms (no translation). To include an origin offset, use OrthoFrame, which combines an OrthoBasis with an origin point.

template<typename Scalar , uint N>
static OrthoBasis vcl::OrthoBasis< Scalar, N >::fromNormal ( const PointType &  normal)
inlinestatic

Constructs a right-handed basis from a normal vector.

Two orthonormal in-plane vectors are computed automatically using Point::orthoBase and stored as axis(0) and axis(1). The normalised normal is stored as axis(2).

Note
The input normal must be non-zero; it is normalised internally.
Parameters

Returns
