Detailed Description

template<typename DerivedRenderApp>
class vcl::HeadlessManager< DerivedRenderApp >

The HeadlessManager class provides a window manager for headless rendering.

It simulates a window without actually displaying it, which is useful for off-screen rendering, automated testing, or server-side rendering where a physical display is not available.
