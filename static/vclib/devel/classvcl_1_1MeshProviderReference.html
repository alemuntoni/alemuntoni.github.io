Detailed Description

template<MeshConcept MeshType>
class vcl::MeshProviderReference< MeshType >

A standalone MeshProvider that acts as a reference to an existing Mesh.

This class implements the AbstractMeshProvider interface without requiring the mesh to inherit from the CRTP Mixin. It acts as an adapter, delegating calls to the referenced mesh. Since it only holds a pointer to the mesh, it must not outlive the mesh it references.

Example of usage:

TriMesh m;
// ... fill mesh ...
MeshProviderReference<TriMesh> provider(m);
Point3d p = provider.vertexPosition(0);
