Detailed Description

template<typename Scalar = float>
class vcl::mesh::TransformMatrix< Scalar >

The TransformMatrix class represents a component that stores a 4x4 matrix that can be used for an affine transformation. This class is used as a component of a Mesh.

The member functions of this class will be available in the instance of any Mesh that will contain this component.

For example, if you have a Mesh m with the TransformMatrix component, you can access and modify its transform matrix:

m.transformMatrix().setIdentity();
auto mat = m.transformMatrix();
Template Parameters
ScalarThe type of the scalar that will be used to represent the matrix (default: float).
