Detailed Description

Free functions for asserting container compactness, checking/asserting mesh topology, and enabling/asserting component availability at compile-time and run-time.

template<ElemId ELEM_ID, CompId COMP_ID, MeshConcept MeshType>
bool vcl::enableIfElementComponentOptional ( MeshType & m)

Enables the given optional Component COMP_ID in element ELEM_ID of mesh m, and returns true if it is available after the call. If the component is non-optional, returns true immediately. If the mesh or element does not have the component, returns false.
