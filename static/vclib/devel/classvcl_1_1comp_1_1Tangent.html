Detailed Description

template<PointConcept P, bool OPT = false>
class vcl::comp::Tangent< P, OPT >

The Tangent class represents a component that stores a tangent vector and a boolean indicating handedness (right-handed if true) of a mesh element.

For example, if you have a Vertex Element v with the Tangent component, you'll be able to access this component member functions from v:

auto& tn = v.tangent();
bool rh = v.tangentRightHanded();
auto btn = v.bitangent(); // requires Normal component
Template Parameters
PThe type of the tangent vector. This template argument must satisfy the PointConcept.
OPTIf true, the component will be optional.

P vcl::comp::Tangent< P, OPT >::bitangent ( this auto && self)
inline

Computes and returns the bitangent vector using the tangent and normal vectors.

The bitangent is computed as the cross product between the tangent and the normal vectors. The direction of the bitangent depends on the handedness of the tangent.

Exceptions
vcl::MissingComponentExceptionif the Normal component is not available or not enabled on the element.
