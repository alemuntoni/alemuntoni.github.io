Detailed Description

template<ElemId ELEM_ID, typename ContainerType, typename... Comps>
class vcl::ElementProxy< ELEM_ID, ContainerType, vcl::TypeWrapper< Comps... > >

Lightweight proxy object to access an element's data in the Structure of Arrays (SoA) ElementContainer.

The ElementProxy acts as an Object-Oriented view over the Structure of Arrays. It is meant to be instantiated on the fly (passed by value) and provides access to the components' data by delegating the calls to the underlying Container.

It will provide all the member functions of the components in the ComponentListWrapper.

inline

Returns a reference to the value of the component with COMP_ID.

Only attribute components (such as POSITION, NORMAL, COLOR, QUALITY, TEX_COORD, TANGENT, PRINCIPAL_CURVATURE, MATERIAL_INDEX) can be accessed through this function. Structural, topological, and TTVC components (like VERTEX_REFERENCES, ADJACENT_*, BIT_FLAGS, WEDGES) are excluded at compile time to protect container invariants.

Constness is propagated automatically from the ElementProxy / Container.
