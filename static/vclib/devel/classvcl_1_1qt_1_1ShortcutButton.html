Detailed Description

A push button that, when clicked, listens for the next key or mouse input and reports it as a string via the onInputCaptured callback.

Used by InputBindingsWidget to let the user interactively (re)assign a shortcut to an action. The kind of input it listens for (key, mouse button or scroll axis) is restricted by mExpectedType, so that e.g. a button editing a mouse binding ignores keyboard events.
