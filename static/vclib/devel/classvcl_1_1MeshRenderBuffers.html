template<MeshConcept Mesh>
void vcl::MeshRenderBuffers< Mesh >::updatePointsVertexBuffers ( const MeshRenderBuffers< MeshType > & mrb,
Points & points )
inlinestaticprivate

Updates the internal buffer references in the given Points object.

This must be called after a swap to update the internal buffer references in Points. OwnedOrRefBuffer stores a pointer to the VertexBuffer object, so after swapping MeshRenderBuffers, the pointers in Points would still point to the other MeshRenderBuffers's members. We must unconditionally update them, even if they are invalid, to ensure they point to the correct memory addresses within this object.

Parameters
[in]mrbThe mesh render buffers object to read vertices from.
[in,out]pointsThe points primitive object to update.
