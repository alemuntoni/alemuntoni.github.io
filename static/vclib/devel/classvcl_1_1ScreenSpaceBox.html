Detailed Description

A screen-space overlay box drawn in pixel coordinates.

ScreenSpaceBox renders a filled rectangle in screen space using bgfx. The box is defined by a Box2d (min-max corners in pixel coordinates). This class manages its own vertex and index buffers.
