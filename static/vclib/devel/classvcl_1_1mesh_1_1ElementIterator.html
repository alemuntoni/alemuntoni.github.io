Detailed Description

template<typename ContainerType>
class vcl::mesh::ElementIterator< ContainerType >

Random-access iterator over the elements of an ElementContainer.

It yields lightweight ElementProxy objects by value. By default, it jumps elements that are marked as deleted (jumpDeleted = true).
