Detailed Description

Describes a single selection operation.

Composed of three orthogonal dimensions:

  • primitive: what to select (vertex, face, ...)
  • action: how to select (regular, add, subtract, all, none, invert)
  • visible: whether to consider only screen-visible primitives (only meaningful for faces)

Braced initialization: SelectionMode mode{SelectionPrimitive::FACE, SelectionDragAction::ADD, true};
