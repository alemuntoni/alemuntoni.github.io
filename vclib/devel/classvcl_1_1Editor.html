Detailed Description

template<typename ViewerDrawer>
class vcl::Editor< ViewerDrawer >

The Editor abstract class is a base class for all the editors of the VCLib Render module.

An editor is an object contained in an AbstractViewerDrawer that can "edit" the behavior of the viewer itself. For example, it can be a gizmo that allows to edit the position of a drawable object, or it can be a widget that allows draw additional elements on top of the viewer (e.g. a grid, or a bounding box).
