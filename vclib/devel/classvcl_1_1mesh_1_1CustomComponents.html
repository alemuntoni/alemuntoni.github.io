Detailed Description

The CustomComponents class is a Mesh component that manages runtime-defined custom components at the mesh level (horizontal dynamic attributes stored on the mesh).

Each mesh-level custom component is identified by a unique name (std::string) and stores an instance of any type (std::any), with its std::type_index tracked.

E.g., to add and access a mesh-level custom component from a mesh m:

m.addCustomComponent<int>("iteration", 42);
int iter = m.customComponent<int>("iteration");
