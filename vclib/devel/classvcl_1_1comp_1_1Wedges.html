Detailed Description

template<typename Comp, int N = 3, bool OPT = IsCompOptional<Comp>::value>
requires WedgeableComponent<Comp>
class vcl::comp::Wedges< Comp, N, OPT >

The Wedges component represents a collection of per-wedge attributes associated to the vertices/corners of an Element (typically Face).

It is a ContainerComponent that wraps a container of attributes (e.g. Color, TexCoord, Normal) whose size matches the vertex count of the face (e.g. 3 for triangles, dynamic for polygons).

For dynamic polygons (N < 0), Wedges is automatically marked as TIED_TO_VERTEX_COUNT = true, so resizing the polygon's vertices automatically resizes the wedge buffers.

Indexing in Wedges: Local Corner Positions vs. Global Vertex Indices

As a ContainerComponent:

  • Local Corner Position (uint): Accessing wedges is always indexed by a 0-based local corner position uint i (0 <= i < f.vertexCount()). Calling f.wedge(uint i) returns a WedgeProxy bound to corner i. In addition, wedge.index() returns this local uint position.
  • Global Vertex Index (IndexType): Each wedge corner corresponds to a topological vertex of the face. Calling wedge.vertexIndex() delegates to f.vertexIndex(i) and returns the global index (IndexType) of the corresponding vertex in the mesh's VertexContainer.

Access to individual wedges is provided via Face::wedge(uint i) (returning WedgeProxy) or Face::wedges() (returning WedgeContainerProxy).

Template Parameters
CompThe base component type (e.g. Color, TexCoordf, Normal3f) or raw value type.
NThe number of wedges per element (default 3; negative for dynamic/polygonal faces).
OPTTrue if the component is optional (defaults to Comp::IS_OPTIONAL if Comp is a Component).
