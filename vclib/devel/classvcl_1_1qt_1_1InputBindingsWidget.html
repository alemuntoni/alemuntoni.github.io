Detailed Description

A widget listing all the actions of a single AbstractInputActionMap, each with a ShortcutButton to view and reassign its current binding.

Edits made by the user are buffered in mPendingBindings and are only written back to the underlying action map when applySettings() is called, so that closing the settings dialog without applying discards the changes.
