Detailed Description

template<typename ComponentList, typename ParentMesh, std::unsigned_integral Index, template< typename... > class Element>
class vcl::mesh::ElementContainer< ComponentList, ParentMesh, Index, Element >

The ElementContainer class is the low-level base container that manages the Structure of Arrays (SoA) storage for a specific mesh element type.

It acts as the backbone for concrete element containers (such as VertexContainer, FaceContainer, and EdgeContainer). For each component in the ComponentList, ElementContainer maintains a dedicated, contiguous vector in a ParallelVectorsTuple.

Key responsibilities:

  • Manages memory allocation, resizing, and element count tracking (both total allocated size and active non-deleted count).
  • Tracks deleted elements via the mandatory BitFlags component and provides compacting routines (compactElements, elementCompactIndices).
  • Controls dynamic enabling and disabling of optional components.
  • Coordinates topological updates and reference remapping across containers when elements are compacted (updateReferences).
  • Exposes low-level access to elements as strongly-typed flyweight proxies via the template template parameter Element (e.g. Vertex, Face).
Template Parameters
ComponentListA vcl::TypeWrapper wrapping the list of components that compose the element (e.g. VertexComponents, FaceComponents). Each component determines a parallel vector column in the underlying SoA storage. Must include the BitFlags component.
ParentMeshThe enclosing Mesh class type to which this container belongs, or void if used as an unbound placeholder prior to mesh rebinding. Allows element proxies to navigate across containers (e.g. from Face to Vertex) through container.parentMesh().
IndexAn unsigned integral type used for element indices. Determines index representation width across the container (e.g. uint32_t or uint64_t).
ElementA template template parameter representing the concrete element proxy class template (e.g. Vertex, Face, Edge), instantiated internally as Element<ElementContainer> (ElementType) and Element<const ElementContainer> (ConstElementType). This allows ElementContainer and its iterators to instantiate and return strongly-typed element proxies directly without intermediate type erasure.
