Detailed Description

template<typename ContainerType>
class vcl::Edge< ContainerType >

The Edge class represents the runtime proxy (view) of an Edge element in a mesh container.

It inherits from ElementProxy and provides object-oriented access to the per-edge components stored in the container's Structure of Arrays.
