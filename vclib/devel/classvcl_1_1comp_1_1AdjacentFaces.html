Detailed Description

template<int N = -1, std::unsigned_integral Index = uint, bool TTVC = false, bool OPT = false>
class vcl::comp::AdjacentFaces< N, Index, TTVC, OPT >

The AdjacentFaces class is a container of Face indices. It can be used by any Element (Vertex, Face, Edge) to store face adjacency information.

It is a random access container having static or dynamic size, depending on the value of N (a negative number means dynamic).

Dual Index Spaces: Global Face Indices vs. Local Adjacency Positions

It is essential to distinguish between the two indexing spaces in this component:

  1. Global Face Index (IndexType):
    • The global index or ID of a face inside the mesh's FaceContainer (m.face(fi)).
    • Typed as IndexType (32 or 64 bit).
    • Sentinel value: NULL_INDEX (vcl::NULL_INDEX<IndexType>). Indicates that there is no adjacent face at this slot (e.g. a boundary edge of a mesh).
    • Returned by adjFaceIndex(uint i) and adjFaceIndexMod(int i).
    • Passed to search functions like containsAdjFace(IndexType fi) and indexOfAdjFace(IndexType fi).
  2. Local Adjacency Position (uint):
    • The 0-based position or slot i within this element's adjacency list (0 <= i < adjFaceCount()), e.g. edge 0, 1, 2 of a triangle face.
    • Always typed as uint (uint32_t).
    • Sentinel value: vcl::UINT_NULL (0xFFFFFFFF), indicating that the queried face was not found in this element's adjacency list.
    • Passed as the position uint i to adjFace(uint i), adjFaceIndex(uint i), and setAdjFace(uint i, IndexType fi).
    • Returned by indexOfAdjFace(IndexType fi).
Template Parameters
NThe size of the container, representing the number of storable adjacent faces. If negative, the container is dynamic.
IndexThe unsigned integral type used to store indices (default uint).
TTVCIf true, the container size will be tied to the vertex count of the element (e.g. on polygon faces).
OPTIf true, the component is optional.
