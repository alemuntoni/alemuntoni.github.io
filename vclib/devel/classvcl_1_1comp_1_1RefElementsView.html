Detailed Description

template<typename MeshType, typename ContainerType, ElemId REF_ELEM_ID>
class vcl::comp::RefElementsView< MeshType, ContainerType, REF_ELEM_ID >

View class providing lazy access to referenced elements, with fast component access paths that bypass ElementProxy construction.

Inherits from std::ranges::transform_view to reuse standard C++ range and iterator machinery with zero boilerplate.
