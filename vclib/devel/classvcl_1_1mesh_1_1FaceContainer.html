Detailed Description

template<HasRequiredFaceComponents CompList, std::unsigned_integral Index = uint, typename ParentMesh = void>
class vcl::mesh::FaceContainer< CompList, Index, ParentMesh >

FaceContainer stores the per-face data in a Structure of Arrays (SoA), and it is meant to be used as a template parameter of the Mesh class.

It accepts the Face component list (satisfying HasRequiredFaceComponents), instantiates the underlying storage and exposes the Face element view.

Template Parameters
CompListThe face components type (e.g. FaceComponents<BitFlags, TriangleVertexReferences<uint>>).
IndexThe index type (default uint).
ParentMeshThe parent mesh type. On Mesh instantiation, this is automatically set to the Mesh type. Default is void.

void vcl::mesh::FaceContainer< CompList, Index, ParentMesh >::clearFaces ( )
inline

Clears the Face container of the Mesh, deleting all the faces.

The contained face components are actually removed from the container, not only marked as deleted. Therefore, the container will have size 0 (faceContainerSize() == 0) after the call of this function.

Warning
Any index or reference to faces in the Mesh will be left unchanged, and therefore will point to invalid faces.

auto vcl::mesh::FaceContainer< CompList, Index, ParentMesh >::faces ( bool jumpDeleted = true)
inline

Returns an ElementContainerProxy object that allows to iterate over the faces of the container, providing begin() and end() member functions.

This member function is very useful when you want to iterate over the faces using the C++ range-based for loop syntax:

for (Face f : m.faces()) {
// do something with this face
}

The iterator used to iterate over faces is automatically initialized to jump deleted faces of the container. You can change this option by calling this function with jumpDeleted = false.

Parameters
[in]jumpDeleted(default: true): boolean that tells if the iterator should jump deleted faces.
Returns
An object having begin() and end() functions, allowing to iterate over the container.

Reserves a number of faces in the container of Faces. This is useful when you know (or you have an idea) of how many faces will be added to a new or existing mesh. Calling this function before any addFace() call will avoid unnecessary reallocations of the container, saving execution time.

The philosophy of this function is similar to the one of the reserve() function of the std::vector class.

Resizes the Face container to contain n faces.

If the new size is greater than the old one, new faces are added to the container. If the new size is smaller than the old one, the container is truncated to n faces (faces beyond n are removed).

Warning
Any index to removed faces in the Mesh will be left unchanged, and therefore will point to invalid faces.
Parameters
[in]nthe new size of the Face container.

Updates references to the faces of this mesh according to the mapping stored in the newIndices vector.

This function is useful when faces are deleted, compacted, or permuted, and you want to update all references stored across the mesh containers to point to their new indices.

Note
This function does not change the position of the faces in this container. It updates face references stored in this and other containers of the mesh.
Parameters
[in]newIndicesA vector mapping old face indices to new ones. If a face was deleted or should become unreferenced, its mapping entry must be NULL_INDEX.
