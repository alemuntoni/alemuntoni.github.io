Detailed Description

template<PointConcept P, bool OPT = false>
class vcl::comp::Position< P, OPT >

The Position class represents a N-Dimensional point that will be part of an Element (e.g. Vertex...).

Allows to get and set an object that represents a position in a space. The type of this object must satisfy the PointConcept.

For example, if you have a Vertex Element v with the Position component, you'll be able to access this component's member functions from v:

auto pos = v.position();
Template Parameters
PThe type of the position. This template argument must satisfy the PointConcept.
