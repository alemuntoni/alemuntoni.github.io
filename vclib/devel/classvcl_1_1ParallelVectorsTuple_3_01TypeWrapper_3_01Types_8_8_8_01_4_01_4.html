Clears the contents of all vectors and sets the global size to 0.

Note: Unlike resize and reserve, this operation clears ALL vectors, including the disabled ones, to ensure no memory is leaked.

◆ deserialize()

void vcl::ParallelVectorsTuple< Types >::deserialize ( std::istream & is)
inline

Deserializes the parallel vectors tuple from the given input stream.

Reads the size, the enabled flags of all vectors, and the contents of each enabled vector. Disabled vectors are cleared. For trivially copyable types under native little-endian, vectors are deserialized via bulk I/O; otherwise, elements are deserialized individually.

Parameters
isThe input stream to read from.
