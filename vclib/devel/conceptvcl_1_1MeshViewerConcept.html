Detailed Description

Concept that verifies if a class provides the standard mesh viewer interface.

A type satisfies MeshViewerConcept if it provides methods to add, insert, remove, update, and clear meshes, as well as methods to query the selected mesh, refresh editors, fit the scene, and show the window.

Template Parameters
TThe type to be checked against the MeshViewerConcept.
