Detailed Description

List of Algorithms that delete elements from a mesh based on a given filter condition.

These algorithms allow to conditionally delete mesh elements (vertices, faces, edges) in-place based on a filtering function or range. Elements matching the condition will be deleted, and all internal topology references pointing to the deleted elements will be automatically updated and invalidated (set to MeshType::NULL_INDEX).

You can access these algorithms by including #include <vclib/algorithms/mesh.h>

auto vcl::deleteEdgesIf ( MeshType & m,
const std::function< bool(typename MeshType::ConstEdge)> & edgeFilter )

Deletes all edges from the mesh that satisfy the provided filter function.

This function iterates over all valid edges and deletes those for which the edgeFilter returns true. It also updates all the internal references in the mesh so that references to the deleted edges are properly invalidated.

Template Parameters
MeshTypetype of the input mesh. It must satisfy the EdgeMeshConcept.
Parameters
[in,out]minput mesh, to be modified in-place.
[in]edgeFiltera function that takes an edge as input and returns a boolean value that tells whether the edge should be deleted (true) or kept (false).
Returns
The number of edges deleted.
