Detailed Description

template<CompId COMP_ID, std::unsigned_integral Index, ElemId REF_ELEM_ID, int N = -1, bool TTVC = false, bool OPT = false>
class vcl::comp::ContainerReferencesComponent< COMP_ID, Index, REF_ELEM_ID, N, TTVC, OPT >

Base class for all components that store indices representing topological references to other elements in the Mesh (e.g. vertex references, adjacent faces, adjacent edges, adjacent vertices).

It extends ContainerComponent by defining the referencesElement method and providing a uniform, cache-friendly implementation of updateReferences for mesh compaction.

Dual Index Spaces: Global Element Indices vs. Local Container Positions

Components inheriting from ContainerReferencesComponent manage topological relationships by operating in two distinct index spaces:

  1. Global Element Index (IndexType):
    • Represents the ID/location of a referenced element within the mesh's corresponding ElementContainer (REF_ELEM_ID, e.g. VertexContainer or FaceContainer).
    • Configurable as 32-bit (uint32_t) or 64-bit (uint64_t).
    • The sentinel representing a null, missing, or unassigned reference (e.g. a boundary edge with no adjacent face) is NULL_INDEX (vcl::NULL_INDEX<IndexType>).
    • Returned by refIndex(self, uint i) and accepted by setRef(self, uint i, IndexType idx) and indexOfRef(self, IndexType idx).
  2. Local Container Position (uint):
    • Represents the 0-based offset/slot i within this element's local reference container (0 <= i < refCount(self)), e.g. corner 0, 1, 2 of a triangle face.
    • Always typed as uint (uint32_t) because local topological cardinalities (e.g. face degree, vertex valence) are small and do not scale with total mesh size.
    • The sentinel representing an invalid position or an element not found in this container is vcl::UINT_NULL (0xFFFFFFFF).
    • Passed to refIndex(self, uint i) and returned by indexOfRef(self, IndexType idx).
Template Parameters
COMP_IDThe unique identifier of the component.
IndexThe unsigned integral type used to store indices (default uint).
REF_ELEM_IDThe ElemId of the referenced elements (e.g. ElemId::VERTEX).
NThe size of the reference container: static (N >= 0) or dynamic (N < 0).
TTVCTrue if the component container size is tied to the vertex count.
