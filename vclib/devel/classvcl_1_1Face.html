Detailed Description

template<typename ContainerType>
class vcl::Face< ContainerType >

The Face class represents the runtime proxy (view) of a Face element in a mesh container.

It inherits from ElementProxy and provides object-oriented access to the per-face components stored in the container's Structure of Arrays.
