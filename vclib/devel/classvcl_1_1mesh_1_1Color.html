Detailed Description

The Color class represents a RGBA color that is part of a Mesh.

Allows getting and setting the mesh-level color (e.g. default/diffuse color for the entire mesh).

For example, if you have a Mesh m with the Color component, you can access and modify its color:

m.color() = vcl::Color::Red;
auto c = m.color();
