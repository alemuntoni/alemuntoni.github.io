Detailed Description

template<int N, std::unsigned_integral Index = uint>
class vcl::comp::VertexReferences< N, Index >

The VertexReferences class represents a component that stores a container of indices to vertices that will be part of an Element (e.g. Face, Edge, Tetrahedron, etc.).

The container of Vertex references is a random access container that could have static or dynamic size, depending on the value of the template argument N (a negative number means dynamic).

For example, if a Face element should represent only triangles, N could be

  1. In this case, the container will have static size and it can't be resized in any way. If N is -1, the container will have dynamic size and it will be possible to resize it (e.g. if the Face element should represent a polygon).

The member functions of this class will be available in the instance of any Element that will contain this component.

For example, if you have a Face Element f that has the VertexReferences component, you'll be able to access to this component member functions from f:

uint n = f.vertexCount();
auto v = f.vertex(0);
auto vi = f.vertexIndex(0); // Returns IndexType

Dual Index Spaces: Global Vertex Indices vs. Local Corner Positions

It is essential to distinguish between the two indexing spaces in this component:

  1. Global Vertex Index (IndexType):
    • The global index or ID of a vertex inside the mesh's VertexContainer (m.vertex(vi)).
    • Typed as IndexType (32 or 64 bit).
    • Sentinel value: NULL_INDEX (vcl::NULL_INDEX<IndexType>).
    • Returned by vertexIndex(uint i) and vertexIndexMod(int i).
    • Passed to search functions like containsVertex(IndexType vi), indexOfVertex(IndexType vi), and indexOfEdge(IndexType vi1, IndexType vi2).
  2. Local Corner / Vertex Position (uint):
    • The 0-based position or slot i within this element's vertex list (0 <= i < vertexCount(), e.g. 0, 1, 2 for a triangle face; 0 to $k-1$ for a polygon).
    • Always typed as uint (uint32_t).
    • Sentinel value: vcl::UINT_NULL (0xFFFFFFFF), indicating "not found".
    • Passed as the position uint i to vertex(uint i), vertexIndex(uint i), and setVertex(uint i, IndexType vi).
    • Returned by indexOfVertex(IndexType vi) and indexOfEdge(IndexType vi1, IndexType vi2).
Note
This component is usually the main component of an Element, and therefore is automatically enabled in the Element's container and cannot be disabled.
Several components are Tied To Vertex Count: in other words, they are composed by a container that has the same size of the VertexReferences and, when the VertexReferences container is resized, also the container of these components is resized automatically.
Template Parameters
NThe size of the container, that will represent the number of storable vertices. If negative, the container is dynamic.
IndexThe unsigned integral type used to store indices (default uint).

Returns the 0-based local index of the edge composed of the two vertices with the given global indices in this element.

The order of the two vertices is not important. The local index of the edge corresponds to the local position of the first vertex found in the container (i.e. edge i connects vertex i and vertex (i+1)n). If the edge is not found, returns UINT_NULL.
