Detailed Description

template<typename Container>
class vcl::mesh::ElementContainerProxy< Container >

Proxy view over an ElementContainer of a Mesh.

It provides range-based iteration over elements (yielding ElementProxy instances), random access via operator[], and high-performance column-oriented access to individual components via ComponentView (e.g. positions(), normals(), colors()).

Iteration over elements or component views automatically skips elements marked as deleted by default (when jumpDeleted is true).
