template<MatrixConcept Matrix, EdgeMeshConcept MeshType>
Matrix vcl::edgeAdjacentEdgesMatrix ( const MeshType & mesh)

Get a #E*LEA Matrix of integers containing the adjacent edge indices for each edge of a Mesh. LEA is the largest edge adjacency size of the mesh. The unused values, as well as entries corresponding to boundary or missing adjacent edges, will be set to the sentinel value of the matrix scalar type (static_cast<Scalar>(-1), which is -1 for signed integer types, -1.0 for floating-point types, or the maximum representable value for unsigned integer types).

This function works with every Matrix type that satisfies the MatrixConcept.

Usage example with Eigen Matrix:

Eigen::MatrixXi EA =
vcl::edgeAdjacentEdgesMatrix<Eigen::MatrixXi>(myMesh);
