Detailed Description

template<typename ContainerType, typename ValueType, typename ReferenceType, typename PointerType = ReferenceType*>
class vcl::mesh::ContainerIndexIterator< ContainerType, ValueType, ReferenceType, PointerType >

Base class for random-access iterators that index into an ElementContainer.

It manages the container pointer, current element index, skipping of deleted elements, random-access movement arithmetic, and comparisons using C++23 deducing this.

Note
When the iterator jumps deleted elements and the container is not compact, +=, -=, +, - and the difference between two iterators have linear cost, since the deleted elements must be skipped one by one. For parallel iterations, use vcl::parallelFor, which handles this case efficiently.

Derived classes (such as ElementIterator and ComponentIterator) only need to provide operator*() and operator->().
