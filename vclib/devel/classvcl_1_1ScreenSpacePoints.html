Detailed Description

Renders a set of 2D points as screen-space splats (squares or circles).

Each point is expanded into a quad procedurally in the vertex shader using programmable vertex pulling.

Constructs a point set from ranges of 2D coordinates and per-point colors.

Parameters
[in]vertsRange of elements convertible to Point2 (must provide x() and y()). Each element contributes one screen-space point at (x, y).
[in]vertColorsOptional range of Color elements. If non-empty, per-point colors are enabled; the size must match vertCoords. Default is empty (falls back to general color).
Note
This constructor creates an owned buffer copy of the input data. The original ranges are not referenced after construction.

[in]vertColorsOptional VertexBuffer containing per-point colors. Expected layout: an array of uint with 4 channels per color in ABGR order (A, B, G, R packed as a single 32-bit integer). The buffer must remain valid for the lifetime of this object.
