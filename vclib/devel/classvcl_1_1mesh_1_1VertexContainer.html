Detailed Description

template<HasRequiredVertexComponents CompList, std::unsigned_integral Index = uint, typename ParentMesh = void>
class vcl::mesh::VertexContainer< CompList, Index, ParentMesh >

VertexContainer stores the per-vertex data in a Structure of Arrays (SoA), and it is meant to be used as a template parameter of the Mesh class.

It accepts the Vertex component list (satisfying HasRequiredVertexComponents), instantiates the underlying storage and exposes the Vertex element view.

Template Parameters
CompListThe vertex components type (e.g. VertexComponents<BitFlags, Position3f, Normal3f>).
IndexThe index type (default uint).
ParentMeshThe parent mesh type. On Mesh instantiation, this is automatically set to the Mesh type. Default is void.

void vcl::mesh::VertexContainer< CompList, Index, ParentMesh >::clearVertices ( )
inline

Clears the Vertex container of the Mesh, deleting all the vertices.

The contained vertex components are actually removed from the container, not only marked as deleted. Therefore, the container will have size 0 (vertexContainerSize() == 0) after the call of this function.

Warning
Any index or reference to vertices in the Mesh will be left unchanged, and therefore will point to invalid vertices.

void vcl::mesh::VertexContainer< CompList, Index, ParentMesh >::reserveVertices ( std::size_t n)
inline

Reserves a number of vertices in the container of Vertices. This is useful when you know (or you have an idea) of how many vertices will be added to a new or existing mesh. Calling this function before any addVertex() call will avoid unnecessary reallocations of the container, saving execution time.

The philosophy of this function is similar to the one of the reserve() function of the std::vector class.

Parameters
[in]nthe new capacity of the vertex container.

void vcl::mesh::VertexContainer< CompList, Index, ParentMesh >::resizeVertices ( std::size_t n)
inline

Resizes the Vertex container to contain n vertices.

If the new size is greater than the old one, new vertices are added to the container. If the new size is smaller than the old one, the container is truncated to n vertices (vertices beyond n are removed).

Warning
Any index to removed vertices in the Mesh will be left unchanged, and therefore will point to invalid vertices.
Parameters
[in]nthe new size of the Vertex container.

inline

Updates references to the vertices of this mesh according to the mapping stored in the newIndices vector.

This function is useful when vertices are deleted, compacted, or permuted, and you want to update all references stored across the mesh containers to point to their new indices.

Note
This function does not change the position of the vertices in this container. It updates vertex references stored in this and other containers of the mesh.
Parameters
[in]newIndicesA vector mapping old vertex indices to new ones. If a vertex was deleted or should become unreferenced, its mapping entry must be NULL_INDEX.

template<HasRequiredVertexComponents CompList, std::unsigned_integral Index = uint, typename ParentMesh = void>
auto vcl::mesh::VertexContainer< CompList, Index, ParentMesh >::vertices ( bool jumpDeleted = true)
inline

Returns an ElementContainerProxy object that allows to iterate over the vertices of the container, providing begin() and end() member functions.

This member function is very useful when you want to iterate over the vertices using the C++ range-based for loop syntax:

for (Vertex v : m.vertices()) {
// do something with this vertex
}

The iterator used to iterate over vertices is automatically initialized to jump deleted vertices of the container. You can change this option by calling this function with jumpDeleted = false.

Parameters
[in]jumpDeleted(default: true): boolean that tells if the iterator should jump deleted vertices.
Returns
An object having begin() and end() functions, allowing to iterate over the container.
