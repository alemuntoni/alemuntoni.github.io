Detailed Description

Manages polygon-to-triangle mapping buffers for a mesh.

This class encapsulates the buffers required to map triangulated indices back to their original polygon indices. It is used by both the selection compute shaders and the surface ID pass.

Uploads the polygon-to-triangle mapping buffers to the GPU.

These three buffers allow shaders to convert from triangle indices back to the original polygon indices.
