Detailed Description

template<typename ContainerType>
class vcl::Vertex< ContainerType >

The Vertex class represents the runtime proxy (view) of a Vertex element in a mesh container.

It inherits from ElementProxy and provides object-oriented access to the per-vertex components stored in the container's Structure of Arrays.
