Detailed Description

template<PointConcept Point = Point3f>
class vcl::mesh::BoundingBox< Point >

The BoundingBox component class represents an axis-aligned bounding box that is part of a Mesh.

The member functions of this class will be available in the instance of any Mesh that will contain this component.

For example, if you have a Mesh m with the BoundingBox component, you can access and modify its bounding box:

m.boundingBox().setNull();
auto bb = m.boundingBox();
Template Parameters
PointThe type of the point that will be used to represent the bounding box corners (default: Point3f). This template argument must satisfy the PointConcept.
