Detailed Description

The CustomComponents class is an Element component that manages the access to runtime-defined custom components (e.g. per-vertex or per-face dynamic attributes).

CustomComponents are components that can be added at runtime. Each custom component is composed of:

  • a name, which is an std::string
  • a type, which needs to be known at compile time when accessed

E.g., to access a CustomComponent of type 'int' called "myCustomComponent" from an element proxy el:

el.customComponent<int>("myCustomComponent");

Since the element proxy is a flyweight view over the container's Structure of Arrays (SoA), this component delegates the actual storage and lookup to the underlying ElementContainer.
