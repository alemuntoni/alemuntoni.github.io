detail::AddressOfView vcl::views::addrOf
inlineconstexpr

The addrOf view applies the address-of operator & on the input view.

It allows to get the pointers of the objects of a range. The resulting view will iterate over the pointers pointing to the object of the input range.

◆ adjEdges

detail::AdjEdgesView vcl::views::adjEdges
inlineconstexpr

View adaptor that gives access to the adjacent edges of the element that has been piped. Every element having the adjacency component (i.e., having the adjEdges() member function) can be applied to this view.

The resulting range contains proxies to the adjacent edges. Proxies of missing adjacencies are invalid (they evaluate to false). If you are interested only on the valid ones, you can use the notNull view:

for (auto ae : e | views::adjEdges | views::notNull) { ... }

◆ colors

detail::ColorsView vcl::views::colors
inlineconstexpr

View adaptor that transforms a range of elements into a range of their colors.

When applied directly to an ElementContainerProxy (e.g. mesh.vertices() | views::colors or mesh.faces() | views::colors), it directly returns a contiguous ComponentView over the SoA buffer without proxy overhead.

When applied to a filtered or transformed range (e.g. mesh.vertices() | views::selected | views::colors), it transforms each element to its color reference.

◆ deref

detail::DereferenceView vcl::views::deref
inlineconstexpr

The deref view the dereference operator * on the input view.

It allows to dereference the pointers of a range. The resulting view will iterate over the objects pointed by the range of pointers.

Note
: no check on the validity of the pointers is performed. If you know that in your range there is the possibility to have nullptr pointers, use first the notNull view:
auto resView = inputRange | notNull | dereference;

◆ notNull

detail::NotNullView vcl::views::notNull
inlineconstexpr

The notNull view allows to filter the pointers of a range. The resulting view will iterate only on the pointers that are not nullptr.

It can be applied also to ranges of objects that are explicitly convertible to bool (e.g. the element proxies of a mesh, that evaluate to false when invalid): in this case, the resulting view will iterate only on the objects that evaluate to true.
