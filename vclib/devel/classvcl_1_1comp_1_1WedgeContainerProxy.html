Detailed Description

template<typename FaceType>
class vcl::comp::WedgeContainerProxy< FaceType >

The WedgeContainerProxy class represents the container view of all wedges (corners) of a specific Face.

It provides:

  1. Range iteration over WedgeProxy (for auto w : f.wedges())
  2. Component views for direct column access (f.wedges().colors(), f.wedges().normals(), etc.)
