Detailed Description

template<typename T>
class vcl::OwnedOrRefBuffer< T >

A class template to manage a buffer that can be either owned (T) or referenced (const T*).

This class wraps a std::variant<T, const T*> and provides a unified interface for both cases. Copy constructor and assignment are deleted to match the semantics of other buffers in the library.

Template Parameters
TThe type of the buffer (e.g., VertexBuffer).
