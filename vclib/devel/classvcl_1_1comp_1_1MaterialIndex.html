Detailed Description

template<bool OPT = false>
class vcl::comp::MaterialIndex< OPT >

The MaterialIndex class represents an unsigned short index that refers to a Material in the Mesh Materials component.

It is typically part of an Element (e.g. Vertex, Face).

For example, if you have a Face Element f with the MaterialIndex component, you can access and modify its material index:

f.materialIndex() = 0;
ushort mi = f.materialIndex();
Template Parameters
OPTIf true, the component is optional (runtime enable/disable).
