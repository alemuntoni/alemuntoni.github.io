Detailed Description

template<FaceMeshConcept MeshType>
class vcl::MeshEdgeUtil< MeshType >

Utility class that represents an edge in a Mesh having Vertices and Faces.

An instance of MeshEdgeUtil stores:

  • the index of the edge in the face (e)
  • the index of the face in its container (f)
  • the indices of the two (ordered) vertices of the edge (v[0], v[1])

This class allows to compare edges in a Mesh. The ordering is done using the vertex indices of the edge (the face index or the edge index within the face are not used for comparison).

Template Parameters
MeshTypeThe type of the mesh. It must satisfy the FaceMeshConcept.

Constructs a MeshEdgeUtil from two vertex indices and an optional face index and edge-in-face index.

Vertex indices are stored in sorted (ascending) order so that the same undirected edge always produces the same MeshEdgeUtil, regardless of winding order.

Constructs a MeshEdgeUtil from the ne-th edge of face pf.

The face proxy is accepted by value (proxies are lightweight) and can be either a mutable or a const face proxy (Face<Container> or Face<const Container>), which is why this constructor is templated on the concrete face proxy type rather than using FaceType<MeshType> directly.
