Detailed Description

template<FaceConcept FaceType, bool CNST = std::is_const_v<FaceType>>
requires comp::HasAdjacentFaces<FaceType>
class vcl::EdgeAdjFaceIterator< FaceType, CNST >

Forward iterator that circulates around the faces adjacent to a given edge of a face.

Starting from a face f and an edge index edge, it iterates over all faces sharing that edge in a non-manifold or 2-manifold mesh.

If FaceType is const or a ConstFace proxy, the iterator automatically yields const face proxies (ConstFaceType<FaceType>). If FaceType is mutable, it yields mutable face proxies (FaceType<FaceType>).

Template Parameters
FaceTypeThe face element type. Must satisfy FaceConcept and have AdjacentFaces component.
CNSTExplicit override for constness (defaults to constness of FaceType).
