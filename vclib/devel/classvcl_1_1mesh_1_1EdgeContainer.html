Detailed Description

template<HasRequiredEdgeComponents CompList, std::unsigned_integral Index = uint, typename ParentMesh = void>
class vcl::mesh::EdgeContainer< CompList, Index, ParentMesh >

EdgeContainer stores the per-edge data in a Structure of Arrays (SoA), and it is meant to be used as a template parameter of the Mesh class.

It accepts the Edge component list (satisfying HasRequiredEdgeComponents), instantiates the underlying storage and exposes the Edge element view.

Template Parameters
CompListThe edge components type (e.g. EdgeComponents<BitFlags, EdgeVertexReferences<uint>>).
IndexThe index type (default uint).
ParentMeshThe parent mesh type. On Mesh instantiation, this is automatically set to the Mesh type. Default is void.

template<HasRequiredEdgeComponents CompList, std::unsigned_integral Index = uint, typename ParentMesh = void>
void vcl::mesh::EdgeContainer< CompList, Index, ParentMesh >::clearEdges ( )
inline

Clears the Edge container of the Mesh, deleting all the edges.

The contained edge components are actually removed from the container, not only marked as deleted. Therefore, the container will have size 0 (edgeContainerSize() == 0) after the call of this function.

Warning
Any index or reference to edges in the Mesh will be left unchanged, and therefore will point to invalid edges.

auto vcl::mesh::EdgeContainer< CompList, Index, ParentMesh >::edges ( bool jumpDeleted = true)
inline

Returns an ElementContainerProxy object that allows to iterate over the edges of the container, providing begin() and end() member functions.

This member function is very useful when you want to iterate over the edges using the C++ range-based for loop syntax:

for (Edge e : m.edges()) {
// do something with this edge
}

The iterator used to iterate over edges is automatically initialized to jump deleted edges of the container. You can change this option by calling this function with jumpDeleted = false.

Parameters
[in]jumpDeleted(default: true): boolean that tells if the iterator should jump deleted edges.
Returns
An object having begin() and end() functions, allowing to iterate over the container.

inline

Reserves a number of edges in the container of Edges. This is useful when you know (or you have an idea) of how many edges will be added to a new or existing mesh. Calling this function before any addEdge() call will avoid unnecessary reallocations of the container, saving execution time.

The philosophy of this function is similar to the one of the reserve() function of the std::vector class.

Parameters
[in]nthe new capacity of the edge container.

void vcl::mesh::EdgeContainer< CompList, Index, ParentMesh >::resizeEdges ( std::size_t n)
inline

Resizes the Edge container to contain n edges.

If the new size is greater than the old one, new edges are added to the container. If the new size is smaller than the old one, the container is truncated to n edges (edges beyond n are removed).

Warning
Any index to removed edges in the Mesh will be left unchanged, and therefore will point to invalid edges.
Parameters
[in]nthe new size of the Edge container.

void vcl::mesh::EdgeContainer< CompList, Index, ParentMesh >::updateEdgeReferences ( const std::vector< Index > & newIndices)
inline

Updates references to the edges of this mesh according to the mapping stored in the newIndices vector.

This function is useful when edges are deleted, compacted, or permuted, and you want to update all references stored across the mesh containers to point to their new indices.

Note
This function does not change the position of the edges in this container. It updates edge references stored in this and other containers of the mesh.
Parameters
[in]newIndicesA vector mapping old edge indices to new ones. If an edge was deleted or should become unreferenced, its mapping entry must be NULL_INDEX.
