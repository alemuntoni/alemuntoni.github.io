Detailed Description

template<CompId COMP_ID, typename Container>
class vcl::mesh::ComponentView< COMP_ID, Container >

A view over a single component column in an ElementContainer.

It provides random access via operator[], raw buffer access via data(), and bidirectional iteration via begin() and end() that respects the container's deleted flags (jumping deleted elements if jumpDeleted is true).

It does not allow mutating the container size or capacity, protecting the Structure of Arrays (SoA) synchronization invariants.
