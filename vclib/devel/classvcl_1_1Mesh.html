Detailed Description

template<typename... Args>
class vcl::Mesh< Args >

The Mesh class represents a generic mesh composed of element containers (VertexContainer, FaceContainer, etc.) and mesh-level components.

The Mesh class will expose all the public members of its containers and its components, and its role is to implement all the functionalities that allow these containers to communicate (e.g. an operation on the vertex container that requires to update also some face information).

Therefore, in this page are documented only the functions that in some way need to modify the status of more than one Container of the Mesh. Other functions are inherited by the Container classes of the Elements of the Mesh, or from its Components, and depend on all the templates that compose a specific Mesh definition.

Template Parameters
ArgsContainer types (e.g. VertexContainer<...>, FaceContainer<...>) and mesh-level components.

ElementContainers is an alias to a vcl::TypeWrapper that wraps all the element container types of the Mesh (i.e. all the types from which the Mesh inherits that satisfy the ElementContainerConcept, such as VertexContainer, FaceContainer, EdgeContainer, …).

This allows algorithms to iterate at compile-time over every element container present in the mesh without having to enumerate specific ELEM_IDs by hand:

// Call f<ContainerType>() for every element container in the mesh:
[&]<typename... Cont>(TypeWrapper<Cont...>) {
(f.template operator()<Cont>(), ...);
}(typename MeshType::ElementContainers{});

Clears the container of ELEM_ID elements in the Mesh, deleting all the Elements.

The contained elements are actually removed from the container, not only marked as deleted. Therefore, the container will have size 0 (mesh.containerSize<ELEM_ID>() == 0) after the call of this function.

The function requires that the Mesh has a Container of Elements having ID ELEM_ID. Otherwise, a compiler error will be triggered.

Note
This function does not cause a reallocation of the container.
Warning
Any references to ELEM_ID elements in the Mesh will be left unchanged, and therefore will point to invalid indices.

ELEM_IDthe ID of the element.

Returns a vector handle to the custom component of type K having the given name associated to the Element having ID ELEM_ID.

The function requires that the Mesh has a Container of Elements having ID ELEM_ID, and that the Element has CustomComponents. Otherwise, a compiler error will be triggered.

The handle can be used like a normal std::vector, but does not have access to the modifiers member functions (resize, push_back...). The handle contains references to the custom component, therefore you can modify the custom component by modifying the element of the handle vector normally. Since the handle stores references, there are no copies performed when calling this function.

For example, assuming that the mesh has a vertex custom component named "cc" of type int:

auto handle = m.elementCustomComponentVectorHandle<

}

Resizes the Element container to contain n Elements of type ELEM_ID.

If the new size is greater than the old one, new Elements are added to the container, and a reallocation may happen. If the new size is smaller than the old one, the container is truncated to n Elements (elements beyond n are removed).
